# Grille de qualité d'un README

Note de 0 à 2 par critère.

| N° | Critère | 0 point | 1 point | 2 points |
|---|---|---|---|---|
| 1 | Titre et accroche | pas de titre de niveau 1 | titre seul, ou description de plus de 5 lignes | un seul titre de niveau 1 ; description de 1 à 5 lignes qui dit quoi et pour qui ; statut signalé (par exemple « données fictives ») |
| 2 | Prérequis explicites | aucun prérequis | outils cités sans version | la version minimale de Python est chiffrée et les autres outils nécessaires sont cités |
| 3 | Installation reproductible | aucune commande | commandes pour un seul système | commandes copiables pour bash et PowerShell, dans l'ordre d'exécution |
| 4 | Usage avec exemples exécutables | aucun exemple | exemple sans résultat affiché | au moins 2 exemples, chacun avec le résultat réel affiché |
| 5 | Blocs de code balisés | aucun bloc de code | au moins un bloc sans langage | tous les blocs ont un langage ; aucune invite `$` devant les commandes |
| 6 | Structure et titres | moins de 4 sections | sections présentes mais niveaux de titres sautés | sections attendues dans un ordre logique, aucun niveau sauté |
| 7 | Éléments visuels utiles | aucun | présents mais sans texte alternatif ni légende | au moins un tableau ou une arborescence, et toute image a un texte alternatif non vide |
| 8 | Tests | aucune mention | commande de test sans résultat attendu | commande de test et résultat attendu décrits |
| 9 | Maintenance et contribution | rien | contribution ou licence seule | procédure de contribution, licence nommée et moyen de contact |
| 10 | Lisibilité du source | lignes de plus de 120 caractères | quelques lignes de plus de 80 caractères | lignes de 80 caractères au plus (hors code et tableaux), sans espace en fin de ligne |
